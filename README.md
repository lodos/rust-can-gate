# Rust CAN Backend

Сервис представляет собой веб-приложение для управления устройством через REST API. 

Он позволяет включать и выключать устройство, проверять его состояние и работать с его VIN (идентификационным номером). Все операции выполняются через HTTP-запросы:

•	/turn_on — включает устройство.
```shell
curl "http://127.0.0.1:5555/turn_on"
```

•	/turn_off — выключает устройство.
```shell
curl "http://127.0.0.1:5555/turn_off"
```

•	/check_state — проверяет текущее состояние устройства.
```shell
curl "http://127.0.0.1:5555/check_state"
```

•	/set_vin — устанавливает VIN устройства (POST-запрос с JSON).
```shell
curl -X "POST" "http://127.0.0.1:5555/set_vin" \
     -H 'Content-Type: application/json; charset=utf-8' \
     -d $'{
  "action": "ABC123VIN"
}'
```

•	/get_vin — получает установленный VIN устройства.
```shell
curl "http://127.0.0.1:5555/get_vin"
```

•	/start_sniffing — Запустить сниффер

Этот маршрут запускает сниффер, который будет отслеживать обмен сообщениями с автомобилем через диагностический порт. Сниффер позволяет отслеживать команды и ответы, передаваемые через OBDII или другие протоколы диагностики.
```shell
curl "http://127.0.0.1:5555/start_sniffing"
```

•	/get_vin_obdii — Получить VIN через OBDII

Этот маршрут запускает сниффер, который будет отслеживать обмен сообщениями с автомобилем через диагностический порт. Сниффер позволяет отслеживать команды и ответы, передаваемые через OBDII или другие протоколы диагностики.
```shell
curl "http://127.0.0.1:5555/get_vin_obdii"
```

Сервис использует асинхронную модель с библиотекой Warp и Tokio для обработки запросов и управления состоянием устройства в многозадачном окружении.
